# Introduction-to-Machine-Learning


[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

![LDA QDA animation](assets/images/1.gif)


A structured collection of notebooks and resources covering the foundations of machine learning — from core terminology through supervised learning, regression, classification, model evaluation, and a hands-on mini project.

## 📚 Contents

| # | Topic | Description |
|---|-------|-------------|
| 1 | **Machine Learning Basics and Terminology** | Core ML vocabulary, types of learning, and the general workflow |
| 2 | **Introduction to Supervised Learning and Regression Models** | Fundamentals of supervised learning and basic regression models |
| 3 | **Advanced Regression Models — Polynomial Regression and Regularization** | Polynomial regression, overfitting, and regularization techniques (Ridge/Lasso) |
| 4 | **Introduction to Classification and Logistic Regression** | Classification fundamentals and the logistic regression algorithm |
| 5 | **Model Evaluation and Cross-Validation** | Train/test splits, cross-validation strategies, and evaluation techniques |
| 6 | **More Than Accuracy: Communicating Model Performance to Non-Experts** | Precision, recall, F1-score, and explaining model performance beyond accuracy |
| 7 | **k-Nearest Neighbors (k-NN) Algorithm** | Instance-based learning and the k-NN algorithm for classification/regression |
| 8 | **Supervised Learning Mini Project** | Applied project consolidating supervised learning concepts on a real dataset |

## 🎯 Objectives

- Build a solid foundation in core machine learning terminology and concepts
- Understand and implement supervised learning models for both regression and classification
- Learn to identify and address overfitting through regularization
- Evaluate models rigorously using cross-validation and metrics beyond accuracy
- Communicate model performance clearly to both technical and non-technical audiences
- Apply supervised learning end-to-end through a mini project

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** scikit-learn, pandas, NumPy, Matplotlib/Seaborn
- **Environment:** Jupyter Notebook

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/Introduction-to-Machine-Learning.git
   cd Introduction-to-Machine-Learning
   ```
2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
3. Launch Jupyter Notebook and explore the folders in order
   ```bash
   jupyter notebook
   ```

## 📈 Project Highlight
