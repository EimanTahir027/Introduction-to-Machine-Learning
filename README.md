## 🎭 Role Play: More Than Accuracy

> **Communicating Model Performance to Non-Experts**

This repo explores why **accuracy alone** is often misleading when evaluating a machine learning model. Topics covered:

- When accuracy becomes a poor metric (e.g., imbalanced datasets)
- Precision, recall, and F1-score in plain language
- Using confusion matrices to tell the full story
- Presenting trade-offs in a way stakeholders can act on

## 🚀 Key Takeaways

- Always consider the **business context** before choosing a metric.
- Visual tools (charts, confusion matrices) beat raw numbers for non-expert audiences.
- Good communication is part of good data science.
